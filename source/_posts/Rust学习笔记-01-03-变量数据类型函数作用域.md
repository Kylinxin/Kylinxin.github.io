这篇笔记整理 Rust 入门阶段最基础的三个主题：变量和可变性、数据类型、函数与作用域。每个章节都对应一个独立的 `.rs` 文件，可以在 Cargo 项目中单独运行。

运行方式示例：

```bash
cargo run --bin lesson01_variables_mutability
cargo run --bin lesson02_data_types
cargo run --bin lesson03_functions_scope
```

## 01 变量和可变性

对应源文件：`src/bin/01_variables_mutability.rs`

运行命令：

```bash
cargo run --bin lesson01_variables_mutability
```

### 源代码

```rust
fn main() {
    // Rust 变量默认不可变。不可变能减少意外修改，让代码更容易推理。
    let language = "Rust";
    println!("正在学习: {language}");

    // 如果需要修改变量，必须显式写 mut。
    let mut score = 0;
    score += 10;
    println!("当前分数: {score}");

    // shadowing（遮蔽）会创建一个新的同名变量，不要求原变量是 mut。
    // 常用于把一个值转换成另一种形式。
    let spaces = "   ";
    let spaces = spaces.len();
    println!("空格数量: {spaces}");

    // const 是编译期常量，必须写类型，通常使用全大写命名。
    const MAX_POINTS: u32 = 100;
    println!("满分: {MAX_POINTS}");
}
```

### 解读

这一节的核心是理解 Rust 为什么默认让变量不可变。Rust 鼓励先写不可变变量，只有确实需要修改时才加 `mut`。这样可以让程序状态更稳定，也能减少因为意外赋值带来的错误。

```rust
let language = "Rust";
```

这行代码定义了一个不可变变量 `language`。定义之后不能再给它重新赋值。例如下面这种写法会报错：

```rust
language = "Go";
```

如果变量确实需要改变，就要使用 `mut`：

```rust
let mut score = 0;
score += 10;
```

`mut` 的意思是 mutable，也就是“可变”。这里 `score` 一开始是 `0`，后面通过 `+= 10` 改成了 `10`。

这一节还展示了一个很重要的概念：shadowing，也叫“遮蔽”。

```rust
let spaces = "   ";
let spaces = spaces.len();
```

这里不是修改原来的 `spaces`，而是重新定义了一个同名的新变量。第一个 `spaces` 是字符串，第二个 `spaces` 是长度数值。遮蔽允许变量在转换过程中复用同一个名字，代码会更紧凑。

`const` 用来定义常量：

```rust
const MAX_POINTS: u32 = 100;
```

常量必须显式写类型，比如这里的 `u32`。常量通常用全大写命名，表示这是一个固定不变的值。

### 本章要点

- `let` 定义变量，默认不可变。
- `let mut` 定义可变变量。
- shadowing 会创建新的同名变量，不是修改原变量。
- `const` 定义编译期常量，必须写类型。
- Rust 通过“默认不可变”帮助程序员写出更稳定的代码。

## 02 数据类型：标量与复合

对应源文件：`src/bin/02_data_types.rs`

运行命令：

```bash
cargo run --bin lesson02_data_types
```

### 源代码

```rust
fn main() {
    // 标量类型：整数、浮点数、布尔值、字符。
    let age: u8 = 20;
    let price: f64 = 19.99;
    let is_active: bool = true;
    let chinese_char: char = '中';
    println!("age={age}, price={price}, active={is_active}, char={chinese_char}");

    // 元组可以组合不同类型，适合表示固定长度的一组值。
    let student: (&str, u8, bool) = ("Kylin", 20, true);
    let (name, student_age, enrolled) = student;
    println!("name={name}, age={student_age}, enrolled={enrolled}");
    println!("也可以用索引访问元组: {}", student.0);

    // 数组长度固定，所有元素类型相同。
    let scores: [i32; 3] = [90, 85, 88];
    println!("第一门成绩: {}", scores[0]);

    // [value; len] 可以快速创建重复值数组。
    let zeros = [1; 5];
    println!("重复数组: {zeros:?}");
}
```

### 解读

Rust 的数据类型可以先分成两大类：标量类型和复合类型。

标量类型表示单个值：

```rust
let age: u8 = 20;
let price: f64 = 19.99;
let is_active: bool = true;
let chinese_char: char = '中';
```

`u8` 是无符号 8 位整数，能表示的范围比较小，但占用空间也小。`f64` 是 64 位浮点数，适合表示小数。`bool` 只有 `true` 和 `false` 两个值。`char` 表示一个 Unicode 字符，所以可以保存中文字符 `'中'`。

复合类型可以把多个值组合起来。第一个例子是元组：

```rust
let student: (&str, u8, bool) = ("Kylin", 20, true);
```

这个元组里有三个元素：字符串切片、年龄、是否在读。元组适合表示固定长度、结构简单的一组数据。

元组可以通过解构取出值：

```rust
let (name, student_age, enrolled) = student;
```

也可以通过索引访问：

```rust
student.0
```

注意，元组索引用点号加数字，不是方括号。

第二个复合类型是数组：

```rust
let scores: [i32; 3] = [90, 85, 88];
```

`[i32; 3]` 表示这个数组有 3 个元素，每个元素都是 `i32`。数组长度固定，不能像 `Vec` 一样随时增长。

重复数组可以这样写：

```rust
let zeros = [1; 5];
```

它会创建一个长度为 5 的数组，里面每个元素都是 `1`。

打印数组时使用：

```rust
println!("{zeros:?}");
```

这里的 `:?` 是调试格式，适合快速查看数组、结构体等复合数据。

### 本章要点

- 标量类型包括整数、浮点数、布尔值和字符。
- `char` 支持 Unicode，可以表示中文字符。
- 元组可以组合不同类型，长度固定。
- 元组可以解构，也可以通过 `.0`、`.1` 访问。
- 数组要求所有元素类型相同，并且长度固定。
- `{:?}` 可以用调试格式打印复合数据。

## 03 函数与作用域

对应源文件：`src/bin/03_functions_scope.rs`

运行命令：

```bash
cargo run --bin lesson03_functions_scope
```

### 源代码

```rust
fn add(a: i32, b: i32) -> i32 {
    // 没有分号的最后一个表达式会作为返回值。
    a + b
}

fn print_title(title: &str) {
    // 参数类型必须显式声明。
    println!("== {title} ==");
}

fn main() {
    print_title("函数与作用域");
    let result = add(3, 5);
    println!("3 + 5 = {result}");

    // 花括号会创建新的作用域，内部变量离开作用域后失效。
    let outer = 10;
    {
        let inner = 20;
        println!("内部可以访问 outer={outer}, inner={inner}");
    }
    // 这里不能再访问 inner，因为它已经离开作用域。

    // 块也是表达式，可以把计算结果赋给变量。
    let doubled = {
        let value = 7;
        value * 2
    };
    println!("块表达式结果: {doubled}");
}
```

### 解读

Rust 使用 `fn` 定义函数：

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

`add` 是函数名，`a: i32` 和 `b: i32` 是两个参数。Rust 要求函数参数必须写明类型。`-> i32` 表示这个函数返回一个 `i32`。

函数体最后一行：

```rust
a + b
```

没有分号，所以它是表达式，会作为函数返回值。如果写成 `a + b;`，它就变成语句，不再返回 `i32`，函数会因为返回值不匹配而报错。

第二个函数没有显式返回值：

```rust
fn print_title(title: &str) {
    println!("== {title} ==");
}
```

它只负责打印内容。`title: &str` 可以理解为接收一段字符串文本。没有写 `-> 类型` 时，函数默认返回 `()`，也就是 unit 类型，表示“没有有意义的返回值”。

`main` 是程序入口：

```rust
fn main() {
    print_title("函数与作用域");
    let result = add(3, 5);
    println!("3 + 5 = {result}");
}
```

程序从 `main` 开始执行。这里先调用 `print_title` 打印标题，再调用 `add(3, 5)`，把结果保存到 `result`。

作用域由花括号决定：

```rust
let outer = 10;
{
    let inner = 20;
    println!("内部可以访问 outer={outer}, inner={inner}");
}
```

内部作用域可以访问外部的 `outer`，但外部不能访问内部的 `inner`。当代码执行离开内部花括号时，`inner` 就失效了。

Rust 的代码块还可以作为表达式：

```rust
let doubled = {
    let value = 7;
    value * 2
};
```

这个代码块最后一行 `value * 2` 没有分号，所以整个代码块的值就是 `14`，最终赋给 `doubled`。

### 本章要点

- `fn` 用来定义函数。
- 函数参数必须显式写类型。
- `-> 类型` 表示返回值类型。
- 函数最后一个没有分号的表达式会成为返回值。
- `{}` 会创建作用域，内部变量离开作用域后失效。
- 代码块也可以作为表达式，把最后一行结果赋给变量。

## 总结

这三个文件覆盖了 Rust 入门最基础的语法：

- 第 01 节解决“变量能不能改”的问题。
- 第 02 节解决“值是什么类型”的问题。
- 第 03 节解决“代码如何组织成函数，以及变量在哪里有效”的问题。

学习 Rust 时可以先把这三个点掌握牢：默认不可变、类型明确、作用域清晰。后面的所有权、借用和生命周期，都会建立在这些基础之上。
